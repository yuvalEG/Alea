# Third-party licences

Alea Scale Shifter and Alea Chord Randomizer include the work below. Each
component's licence requires its notice to be reproduced in software that
ships it, which is what this file is for. It ships with the applications.

Closing the source made this file necessary rather than optional: an open
GPLv3 repository carried these notices implicitly, because the source went
with the binary. A proprietary binary has to carry them explicitly.
